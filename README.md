Personal portfolio and blog built with React 18, TypeScript, TailwindCSS, and Vite. Deployed via GitHub Actions to GitHub Pages.

## Tech Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, Radix UI
- **Build:** Vite with SWC
- **Testing:** Vitest, React Testing Library, Playwright E2E
- **Blog:** MDX with Decap CMS

## Development

```bash
git clone https://github.com/Dbochman/personal-website.git
cd personal-website
npm ci    # Also sets up pre-commit hooks (Husky + lint-staged)
npm run dev    # http://localhost:8080
```

## Validation

```bash
npm run build:content  # Generates the typed content inputs
npm run typecheck     # Checks the application, unit tests, and Vite configuration
npm run lint
npm test -- --run
npm run build
npm run verify-seo-routes
```

The root `tsc --noEmit` command does not check the referenced projects. Use
`npm run typecheck`. CI builds content before this check. The app consumes
validated JavaScript generated by the content scripts; `allowJs` lets TypeScript
infer those module exports without untyped wildcard declarations.

Prerendering and browser tests need Playwright Chromium, or `CI=true` to use an
installed Chrome browser (the same configuration used by GitHub Actions).

Project preview images are examples captured from the tools, not live data.
Regenerate them with a local server running using
`BASE_URL=http://localhost:8080 node scripts/capture-project-previews.mjs`.
